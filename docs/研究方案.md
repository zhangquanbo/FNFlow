# 通用物体法线 Flow Matching 研究方案（修订版）

Oct 21, 2026 · @yilmazemir

本文作为当前研究执行依据，记录实验顺序、对照设置和进入条件。文中的“时间 t”指 flow 状态的时间变量。

## 研究问题与定位

主攻问题：一个小型像素空间条件 flow，在混合质量监督下，能否学到真实几何细节，并迁移到未见物体与场景？贡献要落在“可靠几何细节如何被学习和保留”，而不是“用 FM 做法线”或“加 DINO”。

**主方法固定前提：**

- 高斯起点、欧氏线性路径、随机时间、速度匹配目标、ODE 推理。
- 主协议为单张 RGB 输入、相机坐标系法线；训练可用几何元数据。使用真实 K 的 RGB+K 实验属于附加协议，与仅 RGB 主结果分列。
- 单卡约 24GB 为资源预算，batch 与分辨率依据实测峰值显存确定。

R 和 Xn 是用于分析的对照，不要求满足主方法的全部前提；最终保留原速度匹配目标的 FM 候选从 V/Xv 中选择。

```latex
\epsilon\sim\mathcal N(0,I),\quad z_t=(1-t)\epsilon+t\,n,\quad u=n-\epsilon,\quad \widetilde n=z_t+(1-t)\,v_\theta(z_t,t,I)
```

**范围：** 第一轮只做不透明或近漫反射物体 + 室内场景。透明、强反射、室外作为后续独立评测组；未覆盖的域不写进结论。

**一个要先承认的事实：** 当前部署是 1 步 Euler。在独立高斯起点、纯速度 MSE、无 CFG 的理想最优解下，t=0 的一步终点等于条件均值 E[n|I]，具有点回归性质。当前模型另有 unit/cosine、Geom-CFG 和拟合误差，实际噪声依赖要测量。因此“FM 有什么用”必须由实验回答，不能预设。

## 第 0 步：协议与代码修正

这些是研究基础，不算贡献，但不做完后面所有数字都不可信。历史人脸入口与 17.90° 结果原样保留，新协议结果单独列。

**数据与标签**

- 每个数据源记录：RGB、normal、valid mask、资产/场景 ID、坐标约定、几何法线还是 shading normal、标签来源（渲染 / 深度派生 / 伪标签 / 未明）、K 及有效标记、z-depth 还是 range。
- 法线 resize 先在有效区域插值再单位化；mask 用最近邻；深度断层两侧不混合。
- crop/resize 同步更新 K；水平翻转时明确镜像后的相机坐标约定，使 normal x 分量、ray 和 K 的处理相互一致。
- 同一资产/场景的所有视角与外观版本归入同一划分。
- 旧人脸 normal 来源未明，只作辅助域，不当真实 GT。

**训练**

- 所有损失项乘 valid mask，按有效像素数归一；整批无有效像素则跳过并记日志。
- unit 项作用于未单位化的终点估计。
- 开放 train\_seed / inference\_seed；去掉推理函数内部写死的 seed 42。
- 加验证集选模、EMA（各组一致）、完整 checkpoint（optimizer、AMP scaler、step、RNG 状态）。
- 修正梯度累积末批不足的问题。

**推理与评测**

- 输出 FP32 单位法线存 .npy；PNG 只作显示，且先单位化再编码。
- 评测直接读浮点向量；坐标转换由数据定义决定，禁止用测试 GT 搜索翻轴。
- 新通用实验统一使用正确步长的共享入口；历史复现入口和源码快照保留，旧 infer 不再进入新实验。

**自检样例**（不靠最终误差查 bug）：常量平面、水平翻转前后一致、裁剪后 ray 对应、非法像素被屏蔽、浮点保存往返、相同 seed 可复现、不同 seed 能改变随机初态。输出差异按实测记录，接近零也是合法结果。

## 第 1 步：无需重训的诊断（只用现有 checkpoint）

已有记录中，p=0（no-CFG）26.45° 对 p=0.5（Geom-CFG）17.90°，相差约 8.5°，但训练 dropout、checkpoint 与推理模式混在一起。现有权重可先检查同一 checkpoint 的推理模式效应；训练 dropout 的独立因果收益仍需受控重复训练确认。

| 诊断 | 做法 | 回答的问题 |
| --- | --- | --- |
| D1 CFG × dropout 检查 | p0.3 / p0.5 / p0.7 各跑 no\_cfg、fixed-CFG（s=1.5）、Geom-CFG；p0 的有效主对照为 no\_cfg | 同一权重上推理引导改变多少？训练 dropout 的收益是否仍需复核？ |
| D2 步数 | 预先固定的参考 checkpoint 跑 1/2/4/8 步，统一正确步长 | 多步是否有收益？1 步是否已近最优？ |
| D3 噪声敏感度 | 同图 8 个推理 seed，看逐像素角度离散度及其与误差的相关 | 随机性是有害噪声，还是对应真实歧义？ |
| D4 样本平均 | 8 个样本平均后再评测 | 平均是否提高精度、是否抹掉细节？ |
| D5 OOD 定性 | 33 张通用图 + 少量物体/室内图，看 Geom-CFG 权重 s 的分布 | 人脸外几何上，引导是否被压到 s≈0（退化为无条件人脸先验）？ |

**解释边界：** p0 没有受过零条件训练，对它强行使用 CFG 会调用未训练的无条件输入分支；如运行，仅作异常诊断，不据此比较 CFG 优劣。fixed-CFG 是待加入的实验模式，需与 no-CFG、Geom-CFG 的步长、seed 和输出处理对齐。

**为什么先做：** D1 缩小后续 CFG 候选范围；D2、D3 提供步数和随机性的诊断。它们不能单独证明机制具有“FM 专属性”。FaceScape 已用于历史开发，这些结果仅作实现诊断与域内参考；在通用数据上仍需独立验证。

## 第 2 步：参数化对照（通用数据，不加 DINO/ray）

同一 UNet、同数据、同增强、同 optimizer update 预算、同超参搜索次数。基础参数化对照先固定纯条件设置；根据 D1 增设少量 CFG/dropout 候选，在通用验证集上重新确认，不把人脸结果直接当作通用域最优配置。R 始终保留纯条件强回归对照；如给回归加入条件 dropout，另列结果。

| 编号 | 网络输入 → 输出 | 监督 | 识别什么 |
| --- | --- | --- | --- |
| R | z 固定为 0、t 固定 → 直接输出 n | masked normal MSE + unit + cos | 确定性回归基线 |
| V | 随机 z\_t、t → 速度 v | masked velocity MSE + 终点几何项 | 当前 FM 基线 |
| Xv | 随机 z\_t、t → 终点 f，换算为 v | velocity 空间 MSE + 终点几何项 | 输出参数化（JiT 式 x-pred）的影响 |
| Xn | 同 Xv | normal 空间 MSE + 终点几何项 | 去掉隐式时间权重的影响 |

Xv 与 Xn 的关系（t < 1 时）：

```latex
v_\theta=\frac{f_\theta-z_t}{1-t},\qquad \|v_\theta-u\|^2=\frac{\|f_\theta-n\|^2}{(1-t)^2}
```

**注意事项**

- Xv 在 t→1 时权重为 1/(1−t)²。所有 FM 组统一采样 t ∈ \[0, 1−δ\]，记录 δ，并先做梯度量级预检。这本身改变了时间分布，作为对照协议写明。
- R 只学固定输入设置，而 V/Xv/Xn 覆盖随机状态与时间；1 步部署只调用 t=0，多步则调用多个 t。这是优化任务差异，需要报告，不能据此预判谁会胜出或概括为“FM 无用”。
- unit/cos 系数在验证集上重选，0.25 只是起点。
- 每组同时报告固定预算和充分训练后的结果；未收敛不排名。

**输出：** 从 V/Xv 中选出保留速度匹配目标的 FM 参数化，Xn 用于识别时间权重的影响；得到 FM 与回归在各域、各区域（边界、平面、细结构）的差距；复跑 D2/D3（步数、噪声）在通用数据上的结论。

## 第 3 步：强基线（语义条件与 ray）

给 R 和第 2 步选出的最优 FM 加同一套条件，得到“强回归”和“强 FM”。后面所有机制都要同时加到这两个上比较。

**语义条件**

- 冻结 DINOv2-S/14 或 DINOv3-S，取 2–3 个中间层特征，经轻量投影双线性重采样到 UNet 的 1/4、1/8 尺度，第一版用拼接或加法注入。
- 图像特征只编码一次，所有 ODE 步复用。
- 对齐 patch 网格与 UNet 坐标；几何增强必须先于特征提取，不能复用增强前的缓存特征。
- 冻结编码器参数计入总参数与延迟：DINOv2-S 约 21M，加 UNet 约 64M（未含 adapter）。不能声称整体 <50M。

**ray 条件（单独消融；真实 K 属于 RGB+K 附加协议）**

```latex
r(p)=\operatorname{normalize}\big(K^{-1}[u,v,1]^\top\big)
```

- 已知 K 的数据输入 ray 图；未知 K 时输入缺失标记，训练中随机丢弃 K 以学会退化分支。
- 仅 RGB 主结果不读取测试真实 K；若 K 由 RGB 估计，公开估计方法并计入成本。已知 K 的 RGB+K 结果单列；回归与 FM 使用相同的 K 可用性设置。

**人脸初始化**：随机初始化 vs 人脸 checkpoint 微调，小规模筛选一次；无稳定收益就固定随机初始化。

## 决策节点：走哪条路线

第 3 步得到强回归与强 FM 后，用两个检验决定是否继续主线：

1. **FM 价值检验：** 同数据、同语义与输入协议下，FM 是否有可重复的精度、细节或精度–计算量收益？若有，进入机制筛选；若都没有，暂停 FM 专属机制，先核查先验与成本。
2. **机制独立收益检验：** 候选是否超过静态 q、纯时间权重、可分离 q·a(t) 和普通几何差分，且在物体/室内及关键训练 seed 上重复成立？若没有，继续诊断或停止该候选；若有，再与强回归上的可比监督和最接近文献对照，判断论文定位。

若 FM 优势在加入共同 DINO 后消失，先分析增益是否主要来自语义先验；只有强 FM 本身仍有竞争力且编码器成本突出时才启动路线 B。路线 C 的额外前提是样本变化对应合理几何假设并通过校准/任务验证，D3 方差本身不够。

## 主线：可靠性 × 时间的几何细节监督

假设：不同标签来源的误差结构可能不同；深度派生标签在断层附近可能不可靠，渲染标签也需检查几何法线、shading normal 和边界质量。按“标签可靠性 q”和“flow 时间 t”分配局部几何监督，可能保住可靠折痕和小结构，又不强化标签噪声。

**先诊断，再设计。** 在验证集上按以下维度切误差：直接渲染 vs 深度派生标签；高/低 q 区域；轮廓、折痕、细结构、平面；训练时间 t 区间（用验证 GT 构造 z\_t，只做分析）；物体 vs 室内。只有看到“q 与 t 存在交互”时才继续本线。

**两个必须先做的简单基线**

- **S1 静态可靠性权重 q**：来自标签来源、深度有效性、局部平面拟合残差。q 衡量“标签是否可信”，不是“是否平滑”，真实折痕不能因变化大被屏蔽。第一版不让网络自己预测 q。
- **S2 局部几何变化匹配**：匹配 GT 的法线差分，而不是压小预测梯度。

```latex
L_{\Delta}=\frac{\sum_{(p,q)} w_{pq}\,\big\|(\hat n_p-\hat n_q)-(n_p-n_q)\big\|_1}{\sum_{(p,q)} w_{pq}+\varepsilon}
```

**候选机制**：g(t, q\_p, q\_q, 几何)·L\_Δ。必须依次对比：

1. 原始监督
2. 仅静态 q
3. 仅时间权重 a(t)
4. 可分离的 q·a(t)
5. 候选联合机制

若候选等价于第 4 项，或提升只来自整体损失放大、有效像素数变化、t 采样变化，就不能称为新机制。

**FM 专属性**：将可比的可靠性和几何监督也加到强回归上，并控制损失尺度、有效像素数和调参预算。回归没有 flow 状态时间，不能机械照搬 t；若收益由这些通用监督即可解释，结论改写为“通用法线监督方法”，不说成 FM 专属。

**最接近的已有工作**：[DepthFM v1 §3.3](https://arxiv.org/html/2403.13788v1#S3.SS3) 已在 flow 中间状态的终点深度估计上使用法线辅助损失、GT 边缘产生的置信 mask，以及时间权重 π(t)。因此“时间权重 × 置信 mask”本身已有明确先例。该内容应引用 v1，不能与后续改写的 v2 方法混称。ASN 做可靠局部几何筛选；候选必须超过这些已知机制，并完成进一步查新后才能确定贡献。

**外观一致性放第二顺位**：先用同几何不同材质/光照的小集合测法线漂移；确认是主要故障才做成对训练。pair loss 在数学上只是对内方差项，必须与“同样多成对数据但无 pair loss”比较。

## 备选路线

**B 效率：语义先验蒸馏到小型像素 FM**

- 启动条件：强 FM 有竞争力，但 DINO 编码器成为参数/延迟主体。
- 做法：把带 DINO 的强 FM 作教师，蒸馏到不依赖 DINO 的小 velocity UNet，学生保留自己的 FM 路径。
- 对照：同数据的小回归、小 FM、教师，以及相同蒸馏预算下的回归学生。
- 卖点用精度–延迟–显存曲线说话，对比 Lotus-2、Marigold V2、TransNormal-2 等大模型；“<50M”必须包含所有部署组件。

**C 歧义与校准不确定性**

- 启动条件：D3 显示跨噪声样本的变化稳定地对应合理几何假设（如凹凸反转、材质歧义区域），而非随机抖动。
- 需要单独设计受控歧义集合或下游决策任务；单一 GT 的数据不足以验证多模态后验。
- 对照：逐像素概率回归头（含可学习集中度的 vMF）、混合分布、集成。FM 不独占不确定性表达。
- 指标：误差–不确定性相关、风险–覆盖曲线、角度区间覆盖率、下游收益；best-of-K 只作辅助。

## 数据方案

第一轮训练集以 1–2 万张、物体与室内约各半为预算起点，比例由验证集检查。按资产/场景采样，报告资产数和场景数而不只是图片数。数据获取是独立前置工作，渲染管线先用小规模身份独立的子集打通。

混合质量主线需要训练中确实存在不同质量监督：室内部分加入独立的真实深度派生训练切分，或先用干净几何的受控退化标签做机制预检。仅使用真实数据作验证，不足以证明混合质量训练机制。受控退化只能支持相应模拟条件下的结论；真实域主张仍需真实训练/测试证据。

| 数据组 | 用途 | 标签类型 | 注意 |
| --- | --- | --- | --- |
| Objaverse 筛选渲染（或 LightProp 可取子集） | 物体几何与细节 | 直接渲染，质量需检查 | 保存 normal/mask/K/depth/资产 ID；区分几何法线与带 normal map 的 shading normal |
| Hypersim 子集 | 室内场景结构 | 直接几何 | 世界→相机变换要核对 |
| 原人脸数据 | 复现与辅助域 | 来源未明 | 不承担通用结论 |
| 真实室内训练切分（NYUv2/ScanNet 官方训练部分） | 混合质量训练 | 深度派生 | 按场景与真实验证切分互斥；屏蔽孔洞与遮挡断层 |
| 真实室内验证切分（NYUv2/ScanNet 训练集中留出） | 选模与机制筛选 | 深度派生 | 与测试集严格分开，防止只在合成域上调参 |
| 同几何多外观小集合 | 诊断材质/光照敏感度 | 渲染 | 先只做验证，必要时再入训练 |
| 室外（Virtual KITTI 2 等） | 第二轮扩展 | depth+K 派生 | 屏蔽断层和远景 |

第一轮不同时引入大规模多视图重投影、多光照生成链路和教师伪标签。

使用目标数据集训练部分或验证部分选择模型后，不再把该数据集结果称作严格零样本域泛化；按“目标域适配”和“未见域”分别报告。

## 评测协议

选模、调参、机制筛选全部在验证集（含真实室内验证切分）上完成。方案锁定后统一执行正式测试，可包含预先声明的多个配置、训练 seed 与推理 seed；不依据测试结果继续改方法。历史 FaceScape 诊断单列，不作为新的独立测试证据。

**测试组**

- 物体：未见资产渲染；DiLiGenT、LUCES 单图输入协议，按物体聚合。
- 室内：NYUv2、ScanNet，再扩展 iBims-1、DIODE-indoor。
- 人脸：FaceScape 旧协议单列，仅作历史参照。

**指标**

- mean / median 角误差、angular RMSE、<11.25° / <22.5° / <30°。
- 细节：基于 GT 几何定义的边界带、折痕、细结构分组误差；边界宽度在验证阶段固定。
- 外观鲁棒性：同几何不同光照/材质下的法线漂移，同时报告准确度。
- 统计：关键结论 3 个训练 seed，报告各次结果；区分训练 seed 方差与按资产/场景重采样的区间。

**效率报告**：同硬件、batch=1、同分辨率与精度，报告端到端延迟（中位与高分位）、峰值显存、总参数/可训练参数、ODE 步数与 UNet 前向数（Geom-CFG 为 2K，TTA 另计）、DINO 编码成本。

**外部基线**：Lotus-2、Marigold V2、TransNormal-2、StableNormal、DSINE、RoSE（物体）。只作参考，因果结论依赖同数据同骨干的内部对照；外部模型坐标约定预先固定，不用测试 GT 选翻轴。

| --- | --- | --- |
| [DepthFM v1 §3.3](https://arxiv.org/html/2403.13788v1#S3.SS3) | FM 做单目几何；终点估计的法线辅助损失、置信 mask 与时间权重 π(t) | “时间 × 置信 mask”已有先例；需注明 v1，不能将普通可分离组合视为创新 |
| [ASN](https://arxiv.org/abs/2402.05869) | 可靠局部几何的自适应筛选 | 静态可靠性加权不是新意 |
| [DiCeption](https://arxiv.org/abs/2502.17157) | FM 多任务感知含法线 | 避免“FM 做通用法线”叙事 |
| [Lotus-2](https://arxiv.org/abs/2512.01030) | 单步核心预测 + 确定性 rectified-flow 细节精修 | 不做粗到细叙事 |
| [FE2E](https://arxiv.org/abs/2509.04338) | 一致速度、固定起点的确定性 FM | 单步确定性化已有人做 |
| [Marigold V2](https://arxiv.org/html/2609.08084v1#S3.SS2) | 固定时间的直接 latent 回归，无需积分轨迹；DINOv3 对齐与 Sinkhorn 监督 | 与噪声标签/局部匹配相关的方法比较，不能直接照搬深度损失到方向法线 |
| [TransNormal-2](https://arxiv.org/abs/2609.06665) | 固定集中度 vMF（等价于缩放 cosine）、逆渲染自一致、小波边缘正则 | 不能把已有 cosine 更名为新角度损失；边缘正则需证明额外收益 |
| [Pixel-Perfect Depth](https://arxiv.org/abs/2510.07316) | 像素空间扩散 + 视觉基础模型语义注入 | DINO 注入像素空间 FM 不算新意 |
| [JiT](https://arxiv.org/abs/2511.13720) | 在其像素生成实验中展示 x-pred 的优势，并区分输出与损失空间 | x-pred 作为参数化候选；不能直接推断本项目的卷积 UNet 必然获益 |
| [RoSE](https://arxiv.org/abs/2602.09929) | 物体法线改写为 shading 序列估计 | shading 辅助监督需证明非冗余 |
| [法线不确定性](https://arxiv.org/abs/2109.09881) | 概率法线输出与学习衰减 | 路线 C 的必比基线 |

**不作为独立贡献**：valid mask、浮点输出、坐标修正；DINO 特征、ray、更多数据；固定集中度 vMF（等价于缩放 cosine）；普通法线差分、pair loss、静态置信加权；球面 FM（改变概率路径，本轮不做）；“FM 比回归好/差”的常规消融（单独成文需要更强的新发现）。

继续查新应针对“标签可靠性 × 训练时间 × 局部几何”的具体机制，而不只搜方法名。
